# AdvisorAI-MultiAgent
Este proyecto consiste en el desarrollo de un **sistema de asesoramiento financiero automatizado**, capaz de **diseñar carteras modelo adaptativas** mediante el **uso** de **modelos LLMs y agentes inteligentes**. La solución se construye sobre una innovadora **Agentic Composable Architecture**, que permite la **orquestación dinámica de múltiples agentes especializados**, cada uno con funciones específicas dentro del flujo de análisis financiero.

Se trata de una **herramienta inteligente, flexible y escalable** que democratice el acceso a la planificación financiera personalizada, combinando lo mejor de la **inteligencia artificial conversacional con la teoría moderna de carteras.**
