# AdvisorAI-MultiAgent
Sistema de asesoramiento financiero automatizado, capaz de diseñar carteras modelo personalizadas mediante el uso de modelos LLMs y agentes inteligentes. La solución se construye sobre una innovadora solución Agentic Composable Architecture, que permite la orquestación dinámica de múltiples agentes especializados en flujo de análisis financiero.
